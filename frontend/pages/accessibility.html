Inclusive Design

Accessibility Statement

CyberShield is committed to ensuring digital accessibility for people with diverse abilities, ages, and technological experience.

Our Accessibility Commitment

CyberShield strives to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standards. We design every page to ensure all citizens can easily report incidents, access educational resources, and navigate security guidance regardless of hardware or assistive technology.

Key Accessibility Features

  • Full Keyboard Navigation: All interactive elements, including menus, buttons, forms, and accordions, can be accessed using standard keyboard shortcuts (Tab, Shift+Tab, Enter, Space, Escape).
  • Screen Reader Optimization: Proper semantic HTML5 tags, ARIA roles, states (like aria-expanded and aria-live), and hidden visual cues ensure smooth screen reader experiences.
  • Text Resizing Controls: The utility bar features built-in font resizing tools (A−, A, A+) allowing users to adjust text sizing dynamically without breaking layouts.
  • High Color Contrast: Text and UI controls strictly maintain compliant contrast ratios against backgrounds for effortless readability under all lighting conditions.
  • Reduced Motion Support: CSS keyframe animations and spring transitions automatically respect user OS preferences for prefers-reduced-motion.
  • Visible Focus Indicators: High-contrast focus rings ensure users always know which interactive element is currently focused.

Feedback & Contact

We welcome your feedback on the accessibility of CyberShield. If you encounter any barriers or have suggestions for improvement, please let us know through our support channels or community FAQ section.
